# Waldoge-themed title screen

## Goal
Make Waldoge the dominant first-viewport visual on the existing **WALDOGE: STREETS OF GAINS** title screen without changing menu behavior or gameplay.

## Changes
- Keep the existing original night-city artwork, but place the established Waldoge fighter front and center: yellow Shiba, red-and-white beanie and hoodie, pixel shades, gold chain, red gloves and sneakers.
- Render Waldoge as a live, looping boxer rather than a static picture, using the existing fighter atlas for guard, jab, cross, recovery and footwork poses.
- Keep the official game title highly legible and retain Start Game, Continue, How to Play, Settings, difficulty selection and leaderboard behavior.
- Match the reference composition with the title above, animated Waldoge centered, and menu beneath; keep every element visible on portrait mobile.

## Validation
- Check portrait mobile and desktop title-screen composition.
- Exercise Start Game, Continue state, How to Play, Settings and difficulty selection.
- Run the existing test suite and confirm the production build succeeds.
